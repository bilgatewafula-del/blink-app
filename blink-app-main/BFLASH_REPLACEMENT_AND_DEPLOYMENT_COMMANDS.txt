B-LINK UPDATED PROJECT REPLACEMENT AND DEPLOYMENT (WINDOWS POWERSHELL)

IMPORTANT
- Close the running development server before replacing files.
- Change $project to the actual folder containing your existing B-Link app (the folder that contains package.json).
- Keep your existing .env / .env.local / .env.production files and Vercel environment variables. Do not replace them with example values.
- The update ZIP contains a complete project folder, not individual patch files.

1) Set paths (edit $project to your real path)

$project = "$env:USERPROFILE\Desktop\blink-app"
$zip = "$env:USERPROFILE\Downloads\BLink-BFlash-Updated-Project.zip"
$extract = "$env:USERPROFILE\Downloads\blink-bflash-update"
$backup = "$env:USERPROFILE\Desktop\blink-app-backup-$(Get-Date -Format yyyyMMdd-HHmmss)"

2) Back up the current application

Copy-Item $project $backup -Recurse -Force

3) Extract the complete updated project

if (Test-Path $extract) { Remove-Item $extract -Recurse -Force }
Expand-Archive -Path $zip -DestinationPath $extract -Force

4) Overwrite the project source while preserving local environment files, Git history and installed dependencies

$source = Join-Path $extract "blink-app-main"
robocopy $source $project /E /COPY:DAT /R:1 /W:1 /XD node_modules .git build /XF .env .env.local .env.production

Robocopy exit codes 0 through 7 are normally successful copy outcomes. An exit code of 8 or higher indicates a copy failure.

5) Install the locked dependencies and run a production build

Set-Location $project
npm ci
npm run build

If the build succeeds, continue. If it fails, keep the backup and do not deploy until the error is resolved.

6) Review, commit and push to the existing GitHub repository

 git status
 git add -A
 git commit -m "Upgrade B-Flash feed, interactions and comments UI"
 git push origin main

If your deployment branch is not main, replace main with the actual branch name.

7) Verify the deployment

- Open the deployed B-Link app.
- Sign in with a normal account.
- Check For You, Following, Trending and Latest.
- Check long-press, swipe gestures, playback speed, comments, owner edit/delete and block action.
- Attempt a video upload and record the exact error if it still occurs.

ROLLBACK
If the update causes a problem, stop the server and restore the backup folder contents to $project, or rename the current folder and rename the backup back to blink-app.
